# 20 skills marketing pour Claude

20 skills prêts à l'emploi, construits pour la formation IA Générative de [Mantra](https://www.mantra.work). En accès libre.

Chaque skill est un dossier avec un fichier `SKILL.md` qui transforme Claude en spécialiste d'une tâche marketing : un rôle, une ou deux méthodes reconnues, des règles de rédaction, un process en étapes et un exemple de référence. En bas de chaque fichier, une section « Personnalisation » à remplir avec votre marque.

Ils accompagnent le guide gratuit [Automatiser 90% de son marketing en 30 jours](https://formations.mantra.work/guide?utm_source=github&utm_medium=repo&utm_campaign=linkedin-multi-guidepilote-202610&utm_content=readme).

## Installer un skill

**Dans Claude (application ou web)** : compressez le dossier du skill en `.zip`, puis Personnaliser, Compétences, « + », et téléversez-le. Testez-le dans un nouveau chat.

**Dans Claude Code** : copiez le dossier du skill dans `.claude/skills/` de votre projet.

## Le personnaliser

Ne commencez pas par les 20. Prenez celui qui correspond à une tâche que vous savez déjà bien faire : vous jugerez mieux le résultat.

Ouvrez un nouveau chat, joignez le skill, et demandez :

```txt
Voici un skill que je souhaite personnaliser pour ma marque.
Pose-moi les questions nécessaires pour remplir toutes les
sections de personnalisation (en bas du document), une par une.
Quand tu as toutes mes réponses, restitue le skill complet
avec les sections de personnalisation remplies.
```

Collez de vrais exemples de vos meilleurs contenus plutôt que de les décrire. Nommez vos mots interdits. Décrivez votre audience comme une personne réelle.

Les exemples des skills utilisent une entreprise fictive, Atelio Formation.
